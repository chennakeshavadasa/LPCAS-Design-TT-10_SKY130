# Piecewise Compensated High PSRR Voltage Refrence
Please utilize the file [PBGR.sch](https://github.com/chennakeshavadasa/LPCAS-Design-TT-10/blob/main/PBGR/PBGR.sch) file directly for the layout. Final Design has been uploaded.
## Pins 
- GND (3.3V Rated Power Pin)
- VIN_PBGR, VPBGR1_OUT, VPBGR2_OUT, VPBGR3_OUT (Analog I/O Pin)
- SW1_PBGR, SW2_PBGR, SW3_PBGR, SW4_PBGR, SW5_PBGR, SW6_PBGR, SW7_PBGR, SW8_PBGR, Startup_PBGR (Digital Pins)
